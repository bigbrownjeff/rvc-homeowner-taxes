The historical launch used a staged public-outreach lifecycle. Recipient-specific
preparation, draft text, routing, and send state are intentionally not stored in
this repository.

**How to apply:**
- Treat the live site and its current facts ledger as the source of truth.
- Re-verify factual claims, public links, and framing on the day of publication.
- Keep copy voluntary, nonpartisan, and clear that the project is independent.
- Use an owner-authorized operational system for any direct outreach; do not
  reconstruct a recipient list, mailbox state, or prior-contact status from
  source control.

See `.claude/scratch/outreach-aug1/MANIFEST.md` for the public-safe template.
