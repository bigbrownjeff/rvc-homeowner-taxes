External organizations may be useful public sources or potential amplifiers, but
this repository contains no organization contacts, outreach drafts, or status.

**Guardrails:**
- Do not imply support, affiliation, endorsement, or consent.
- Name an organization on the public site only after explicit written permission
  and use only its approved wording.
- Prefer primary public sources for factual claims and present the project as an
  independent civic effort.
- Keep recipient selection, routing, and replies in an owner-authorized
  operational system, never in source control.
