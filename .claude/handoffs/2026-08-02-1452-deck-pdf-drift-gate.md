## What worked (and why)

**Testing the premise before building the thing Jeff asked for.** He asked for a step that
"re-renders and flags a diff." Rendering `site/deck.html` twice from identical input gives
`6ad2f810…` and `5d04174d…` — Chrome stamps a fresh `/CreationDate` and `/ID` into every
render, so a byte diff fires on *every* run. Ran the two-render experiment first, then
checked what could compare deterministically: `pdftotext -layout` output hashes identical
across renders. Built the gate on text, told Jeff why. An alarm that always rings is worse
than no alarm.

**Cache-busting on the first probe.** Right after deploy, `/RVC_Briefing_8pager.pdf` returned
`application/pdf` with `?cb=$RANDOM` and **HTML** without it. Not a deploy failure —
Cloudflare's edge had cached the 404 body from before the file existed
(`cache-control: public, max-age=14400`). Comparing custom domain against both `pages.dev`
URLs isolated it in two commands. Recorded in DEPLOY.md.

**Negative-case testing the gate.** Clean pass proves nothing. Flipped `147 cosponsors` →
`149` in the deck, confirmed it flagged 6 lines and named each one, reverted, confirmed clean.

**Reading the script before extending it.** The sunset (below) was in the file the whole
time. Extending it blind would have shipped a gate with one day of life.

## What didn't / dead ends

- `gh pr merge` from inside a worktree fails: `fatal: 'main' is already used by worktree at …`.
  Merge from the main checkout. (The merge itself succeeded; only the branch-cleanup half
  errored, which reads confusingly.)
- `gh pr merge` immediately after a push returns `GraphQL: Pull Request is not mergeable` —
  GitHub hasn't computed mergeability yet. `mergeable` reads `UNKNOWN`, then `MERGEABLE`
  seconds later. Wait and retry; nothing is wrong.
- `failack` does not apply to board cards — it's for launchd exit codes only. Removing a
  spurious `failtask` card needs the GraphQL `deleteProjectV2Item` mutation.

## Key decisions

**Text diff, not byte diff** (evidence above). Catches figures, names, dates, copy. Does
**not** catch pure styling drift — accepted, since the failure mode that matters is a
legislator downloading a stale cosponsor count.

**Option 1 on the sunset, Jeff's call.** `daily_posture_sweep.sh` auto-retires when
`TODAY_NUM > 20260802`, i.e. from **today**. From 2026-08-03 it files a retire card and
`exit 0`s before reaching any check. Options offered: (1) let it retire, keep the manual
gate; (2) extend the sunset; (3) split the PDF gate into its own tiny launchd job. Jeff
chose **1**. So the sweep integration in #37 is inert from tomorrow by design, and
`check_pdf_drift.sh` stands alone — it depends on nothing in the sweep.

Two guards so the gate isn't collateral damage when someone acts on the retire card: the
card's text now says **KEEP `scripts/check_pdf_drift.sh`** while deleting the sweep, and the
gate's own header records that from 2026-08-03 the manual pre-deploy run is the only
protection.

**Left alone deliberately:** the deck masthead reads "BRIEFING · JULY 2026" while
`docs/BRIEF_2026-08.md` is the August brief. Figures are current (re-grounded 07-24); only
the label lags. Flagged to Jeff twice as a copy decision, not taken.

## How to reproduce / pick up

```bash
cd ~/Projects/rvc-homeowner-taxes

scripts/check_pdf_drift.sh          # 0 clean, 1 drift, 2 cannot check
scripts/check_pdf_drift.sh --fix    # re-render in place, then commit the PDF
npx wrangler pages deploy           # gate first, always
```

Verify a newly deployed asset with a cache-buster or you will misdiagnose the edge cache:

```bash
curl -s -o /dev/null -w "%{http_code} %{content_type} %{size_download}\n" \
  "https://rvc-taxes.jeffpinto.com/RVC_Briefing_8pager.pdf?cb=$RANDOM"
```

Exercise the sweep's gates from a worktree without touching the main checkout:

```bash
RVC_REPO="$PWD" SWEEP_DRY=1 ./scripts/daily_posture_sweep.sh
```

Key paths: `scripts/check_pdf_drift.sh` · `site/deck.html` (`--paper` token, `#live-banner`)
· `site/RVC_Briefing_8pager.pdf` · `site/index.html` (`04 · For legislators` res-grid) ·
`DEPLOY.md` (gate + edge-cache note + corrected pptx row).

Requires `~/.claude/bin/html2pdf` and `pdftotext` (homebrew poppler). The gate exits **2**,
loudly, if either is missing — it never passes silently.
